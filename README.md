## Run locally

Download or clone the repository and open any project HTML file in a browser. For a local server, run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000/`. No package installation or build step is required.

## Features

- Responsive HTML and CSS with accessible navigation and contact links.
- Google Maps directions, published business hours and sourced public business facts.
- Existing appointment links for BMichaels and Prada The Barber.
- Cafe Soul Cups category filters, weekly-menu Instagram links and catering contact. The site links to Instagram; it does not automatically sync posts.
- Concept imagery is labeled and does not depict actual business interiors, inventory or products.

## Files

The five project HTML files share this repository root with their styles and image assets. `triangle-concepts.css`, `barber.webp` and `care.webp` support the three Triangle concepts. The antiques and Soul Cups pages each have their own styles. `soulcups-cary.js` provides the menu filters.

## Content and limitations

Public details were checked on October 27, 2026 and can change. Source links and concept notices appear in the pages. There is no backend, checkout, live inventory, custom booking system or payment collection. Confirm business details with the owners before an official launch.

This repository contains the website code and public assets only. Private prospect research, sales quotes and outreach drafts are excluded. No reuse license is granted for business names or third-party branding.
